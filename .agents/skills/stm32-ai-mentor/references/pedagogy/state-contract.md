# 学习状态契约

`Student_Profile/events/` 是不可变事实账本，`state.json` 是可重建快照，三个 Markdown 文件和 `sessions/` 是面向人的派生视图。主导师是唯一写者，所有提交都经 `scripts/state_tool.py`。

## 记录范围

- 学习者、目标板/芯片、工具链和教学偏好。
- 当前课程、项目、里程碑、预习与准备度。
- 理论、实践、调试、迁移四维能力与总评价。
- 作业、证据、未验证结论、常见误区、到期复习。
- 上次会话、精确检查点、阻塞项和下一动作。

不保存密钥、密码、身份证明、无关个人信息或完整聊天原文。

## 写入规则

1. 验证快照、事件尾和锁状态。
2. 传入当前 `expected_revision` 和稳定 `idempotency_key`。
3. 事件仅允许 `learning.*`。
4. 先原子提交事件，再原子替换快照；崩溃后由 `rebuild` 重放。
5. 幂等重试返回既有结果；revision 冲突必须重读，不能覆盖。
6. 快照超前、损坏事件或不能证明安全的锁一律 fail closed。
7. 正式开课事件必须声明本课全部必做 `required_milestone_ids`；结课时所有必做里程碑、已验证验收证据和四级作业缺一不可，未满足只能暂停。

## 掌握度

- 0：未接触
- 1：识别/复述
- 2：提示下完成
- 3：独立完成并解释
- 4：延迟后保持且迁移

晋级必须包含 evidence ID。用户口述的实机现象可作为 `reported_by_user` 证据，但不能改写为工具或导师亲自验证。

每次自动本地保存后只向 Kevin 展示：本次进步、仍薄弱处、新作业、复习日期、下一步和 revision，不倾倒整份 JSON。
