# 课堂预习手册模板

每份手册控制在 10–15 分钟阅读量，并按以下顺序呈现。

```text
项目名 / 生活任务 / 最终可见效果
预计预习时长 / 课堂时长 / 安全等级 / 当前验证等级

一、今天为什么值得做
二、学完你能完成、解释、排查什么
三、开始前已经要会什么
四、把原理讲人话（类比 + 信号流 + 例子）
五、本课概念和必要公式
六、必须记住（3–7）/重点理解/会查即可
七、常考常问及实际作用
八、最容易犯的错误
九、器件、工具、软件、安全检查表
十、5 道准备度题（概念、预测、安全）
答案与错题→概念→微课映射
```

题目不能只考术语记忆；至少一题要求预测程序/电路现象，至少一题考安全。通过线固定为 4/5。复测必须换题但保持同一概念和难度，不泄露原题答案。
