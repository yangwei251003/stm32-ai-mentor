# P03 十字路口交通灯：定时器与状态机

**S2｜85 分钟｜低压低风险｜目标：**做两方向互锁交通灯，并能解释状态机为何比延时串更安全。生活场景是把交叉路口的相位与黄灯警示做成桌面模型。

## 可覆写接线表
| 功能 | MCU 信号/外设 | 默认建议或能力要求 | 必须确认事项 |
|---|---|---|---|
| 六路信号灯 | PA0–PA5 / GPIO 输出 | 每灯独立推挽输出 | 实际可用脚、每路限流和 LED 极性 |
| 相位节拍 | TIM2 / Base interrupt | 1s 逻辑节拍 | 时钟频率、NVIC 已启用 |
| 模式按键（选） | 任一 EXTI 输入 | 上拉输入 | 真实板引脚不占 SWD |

## 课前预习手册（10–15 分钟）
- 前置：P01、P02；器材：6×LED、6×电阻、F103、可选按键。每路独立限流，断电布线。
- 通俗理论：状态机像交通指挥表：当前相位、等待时间、下一相位；定时器像不会堵住其他事情的闹钟。
- 必须记住：红绿不可冲突；黄灯是独立相位；定时器中断只置节拍标志；时间单位统一；长 `HAL_Delay` 会阻塞响应。
- 重点理解：`状态+转移条件`；会查：定时器时钟与预分频。常考：状态机优点、PWM/定时器区别。常错：两个绿灯同时亮、在 ISR 内复杂控制、初始状态未定义。
- 小测：1 状态机组成？2 为什么不能两路绿？3 定时器回调宜做什么？4 黄灯为何独立？5 修改时长应改哪？低于4/5微课+新题。

## 课中（85 分钟）
1. **导入/复习 10 分**：展示“两个方向同绿”的危险模型，列安全不变量。
2. **理论 15 分**：状态表 `NS绿/EW红→NS黄/EW红→全红→NS红/EW绿…`，讲节拍标志。
3. **动手 45 分**：
   - M1：CubeMX TIM2 Base 1 s 中断、NVIC；6 GPIO 输出。`void HAL_TIM_PeriodElapsedCallback(...) { tick_1s=1; }`；亮固定安全相位。
   - M2：主循环每次 tick 递增计时，状态到期调用 `apply_phase(phase)`，预期严格循环。
   - M3：按键触发夜间黄闪（可选），但先验证全红切换。
   - 提示阶梯：先画状态表→指出冲突→给 switch 伪码→定时器片段→完整相位表。
4. **验收/迁移 15 分**：视频/日志显示两轮序列；解释全红作用；变化题：行人按钮如何只在安全相位切换。

## BOM、调试与课后
- BOM：LED×6、电阻×6、板/下载器/线；约20–50元。建议 PA0–PA5，可覆写但在接线表记录实际脚。
- 安全门：断电检查每一路均有限流电阻；交通灯模型只作教学显示，不能控制真实道路设备。
- 调试树：不切换→TIM 时钟/NVIC/回调断点；相位乱→初始化 `phase`/数组索引；同时绿→在 `apply_phase` 先全灭再按相位置位。
- 作业：必做改变绿/黄/全红时间；生活应用模拟小区出口；挑战加倒计时显示；复盘记录一次不变量检查。验证声明：LED 实物或逻辑状态日志二者至少其一。
