# P14 USB 虚拟串口传感仪表：USB CDC

**S6｜90 分钟｜中风险（USB 供电/板差异）｜目标：**让 F103 向电脑以 USB 虚拟串口报告传感器数据。场景是即插即用的桌面小仪表。

## 可覆写接线表
| 功能 | MCU 信号/外设 | 默认建议或能力要求 | 必须确认事项 |
|---|---|---|---|
| USB 数据 | PA11=D-、PA12=D+ / USB FS device | 官方 MCU 固定复用事实 | 第三方板的接口、上拉和走线实物确认 |
| USB 供电 | VBUS/5V 板级路径 | 受控电脑端口和数据线 | 不与外部电源回灌、线材可传数据 |
| 传感器 | 已验证 ADC/I2C（选） | 0–3.3V 逻辑 | 不把模块电源噪声带入 USB |
| 验证 | 主机枚举+终端 | CDC 日志 | 无主机证据仅记编译 |

## 课前预习手册（10–15 分钟）
- 前置：P05、P07；器材：确认 USB 硬件电路的 F103 板、数据线、受控电脑 USB 口、0–3.3V传感器。F103 USB D-=PA11、D+=PA12；**不同第三方板（含 Blue Pill）的上拉/USB 接口实现必须实物确认**。
- 通俗理论：USB 像带登记处的总线，枚举后电脑才分配“虚拟串口座位”；CDC 是双方使用的类协议，不等同 UART 电平。
- 必须记住：D+/D- 不可互换；数据线不等于充电线；USB供电回灌需检查；枚举前不要假设COM口存在；F103资源有限，先做最小数据帧。
- 重点理解：CDC 与 UART 的相同/不同；会查：CubeMX USB Device CDC、中断/时钟配置。常考：枚举含义、D+ D-。常错：只用充电线、时钟不满足、把 USB 5V 回灌至外部电源。
- 小测：1 PA11/12作用？2 枚举成功现象？3 充电线问题？4 CDC像什么？5 为何确认板级上拉？低于4/5补救后复测。

## 课中（90 分钟）
1. **导入/复习 10 分**：把一根“能充电却没有串口”的线作为故障案例。
2. **理论 15 分**：时钟—枚举—CDC 端点—主机终端的数据路径，说明板级差异。
3. **动手 50 分**：
   - M1：CubeMX USB Device/CDC，生成工程；先构建，接电脑观察设备管理器（未识别先不接传感器）。
   - M2：在 CDC 用户发送包装中，仅以周期性小帧发送 `ADC=1234\r\n`；传感器数据来自已验证的 P07 路径。
   - M3：对主机命令只置标志，在主循环处理，避免在 USB 回调做阻塞；底层时基仍由 `HAL_GetTick()` 提供。
   - 最小片段：`CDC_Transmit_FS((uint8_t*)msg, strlen(msg));`（仅在生成的 CDC 接口可用时）；须检查忙状态。
   - 提示阶梯：先看枚举→解释线材/时钟→帧伪码→发送片段→完整节流队列参考。
4. **验收/迁移 15 分**：构建日志、主机识别截图/终端日志、传感数据两行；解释为何不把它叫 UART；变化题：添加单位/时间戳。

## BOM、调试与课后
- BOM：有已确认USB电路的板、数据线、电脑、模拟传感器；约15–80元。安全门：不要同时以多个电源无隔离供电；先检查板级 USB 5V 路径。
- 调试树：不枚举→数据线/板级上拉/时钟/CubeMX；枚举后无数据→端点忙/发送节流；断连→供电/线材。
- 作业：必做每秒发一次数据；生活应用桌面传感仪；挑战主机下发采样率；复盘记录一次枚举排错。无主机日志仅标编译。
