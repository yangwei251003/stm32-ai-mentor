# 15 个完整精讲项目

每一课均以 [`../../prestudy-handbook/classroom_contract.md`](../../prestudy-handbook/classroom_contract.md) 为课堂合同。默认芯片为官方 `STM32F103C8Tx`；所谓 Blue Pill 不是官方板型，只有在学习者确认板上 LED、晶振、USB 上拉和供电线路后才可替代接线。所有 HAL 片段为原创教学最小片段，非可直接替换的完整 ST 工程；先以 CubeMX 生成初始化代码。

| ID | 项目 | 课程 | 特别安全门 |
|---|---|---|---|
| P01 | 设备运行状态灯 | S1 | LED 限流、确认极性 |
| P02 | 电子门铃/按键夜灯 | S1–S2 | 按键 3.3 V、蜂鸣器驱动 |
| P03 | 十字路口交通灯 | S2 | 每一路 LED 限流 |
| P04 | 呼吸夜灯与提示蜂鸣器 | S2 | 蜂鸣器电流、勿直驱大负载 |
| P05 | 智能家电串口控制台 | S6 | USB-TTL 3.3 V、交叉 TX/RX |
| P06 | 自动感光台灯 | S3 | 模拟输入不超 3.3 V |
| P07 | 简易数据采集仪 | S3 | 传感器电压范围、DMA 缓冲 |
| P08 | 桌面温湿度显示站 | S4 | I2C 3.3 V、确认上拉 |
