# 执行试点：桌面温湿度显示站

关联项目：`P08/desktop_temp_humidity_station`。本资料定义执行证据，不把“代码生成”或“烧录成功”称为实物通过。

## 冻结前必须提供的硬件护照

开发板正反照片、厂商/完整型号/版本、MCU 顶部丝印；SHT3x 与 SSD1306 模块的正反照片、准确 SKU/MPN、引脚标识、数据手册；供电电压/最大电流；ST-Link 型号/序列号/固件与接法；USB-UART 端口身份、115200 和协议；断电接线表、接线照片、短路与电压测量；可用仪器；以及对烧录、复位、云上传、生产导出的授权。

未知模块不能按“常见模块”直接接线。默认候选仅为 3.3 V SHT3x I2C 模块与 128×64 SSD1306 I2C 模块，实际 SKU 和数据手册冻结后才选驱动和地址。禁止把 5 V 信号直接接到 3.3 V GPIO。

## M0–M7 证据轨

| 里程碑 | 固件/设计行为 | 通过证据 | 失败时的结论 |
| --- | --- | --- | --- |
| M0 | 锁定工具、Nucleo-F103RB 档案、探针与 UART | 版本、序列号、目标电压收据 | 身份不明，停止烧录 |
| M1 | LED 心跳、按键、115200 UART | 3 秒内 JSON：项目、board profile、baseline、固件哈希、自检 | 构建/探针/供电/串口分类 |
| M2 | I2C 扫描与 ACK/NACK | 地址和错误码；传感器拔掉产生故障帧 | 不允许继续显示旧数据 |
| M3 | SHT3x 读取、CRC、状态、超时 | 约 1 Hz 温湿度 JSON | 传感器/SKU/I2C 故障 |
| M4 | SSD1306 显示 | 2 秒内显示新读数或错误状态 | 显示/I2C 故障 |
| M5 | 换算、范围、状态机、协议主机测 | 可重复的测试收据；仿真仅标模拟 | 不作为实机证据 |
| M6 | build → map → plan → 确认 → flash/verify/reset → serial | 单次确认、哈希和串口断言 | 回滚最近通过增量 |
| M7 | Nucleo 和已识别 F103C8 配置 | 两套独立构建/实机证据 | 禁止互相冒用 |

## 验收

从干净暂存目录可重建并保存 ELF/HEX/BIN/MAP 与 SHA-256。启动 3 秒内输出诊断 JSON，以约 1 Hz 输出温湿度，连续 10 分钟无 HardFault、看门狗复位或未处理 I2C 错误。断开传感器、错误地址、断开 OLED 都须有明确错误帧。

提供参考温湿度计时，稳定环境目标为温度 ±1 °C、湿度 ±5 %RH；没有参考仪器时，不宣称精度验收。PCB 载板发布包需无未审查 ERC/DRC 错误，并含 BOM、Gerber、钻孔、PnP、STEP、层图。首板仅在短路检查、供电测量、接口和完整实机测试均有证据后才可记作 V5。
